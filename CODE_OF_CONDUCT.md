# Code of Conduct

Cronboard is a GNOME Shell extension, and it follows the [GNOME Code of Conduct](https://conduct.gnome.org/). It applies to everyone taking part in this project: issues, pull requests, reviews and discussions in this repository and on the extension's page on extensions.gnome.org.

In short: be friendly and patient, be welcoming and respectful, assume people mean well, and take responsibility for what you say and do. Read the full text on the GNOME website.

## Reporting a problem

If someone's behaviour in this project worries you, contact the maintainer, [@seniru-dilmith](https://github.com/seniru-dilmith). GitHub has no private messages, so either use the contact details on that profile, or open a short issue asking to be contacted privately and leave the details out of it.

Reports are kept confidential. The maintainer may remove, edit or reject comments, commits and issues that break this code, and may block people who repeatedly do so.

For behaviour in GNOME's own spaces, such as GNOME's GitLab, Matrix rooms or Discourse, report it to the GNOME Code of Conduct Committee as described on the GNOME website.
